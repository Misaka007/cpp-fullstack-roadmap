# Ubuntu 常用命令

## 1. 文件与目录

```bash
pwd                         # 当前目录
ls -lah                     # 列出文件、权限和大小
find /var/log -type f -name '*.log'
find . -type f -mtime -7    # 最近 7 天修改的文件
cp -a src/ dst/             # 保留属性复制
mv old new
rm -i file                  # 交互删除，避免误删
du -sh * | sort -h          # 按目录大小排序
df -hT                      # 文件系统空间和类型
```

## 2. 文本检索与处理

```bash
grep -RIn 'pattern' path/   # 递归搜索，显示行号
rg -n 'pattern' path/       # 安装 ripgrep 后的快速搜索
sed -n '1,20p' file         # 查看指定行
awk '{sum += $1} END {print sum}' file
sort file | uniq -c | sort -nr
tail -f /var/log/syslog     # 实时跟踪日志
```

管道只传递标准输出；错误输出需要 `2>` 或 `2>&1` 单独处理。

## 3. 权限与用户

```bash
id                          # 当前 UID、GID 和附属组
sudo -l                     # 当前用户可执行的 sudo 规则
chmod 640 file              # owner: rw, group: r, other: ---
chown user:group file
umask                       # 新建文件的默认权限掩码
getfacl file                # 查看 ACL
```

避免使用 `chmod 777` 解决权限问题；应定位文件所有者、所属组、目录执行权限和服务运行用户。

## 4. 进程与资源

```bash
ps aux --sort=-%mem | head
pgrep -af process_name
top                         # 交互查看资源
free -h                     # 内存与 swap
uptime                      # 负载和运行时间
nice -n 10 command          # 降低进程调度优先级
kill -TERM <pid>            # 请求正常退出
kill -KILL <pid>            # 无法处理的进程才使用
```

先使用 `SIGTERM` 让程序清理资源；`SIGKILL` 不能被捕获，也不会执行应用层清理逻辑。

## 5. 网络与端口

```bash
ip addr                     # 网卡地址
ip route                    # 路由表
ss -lntp                    # 监听 TCP 端口和所属进程
curl -I https://example.com # HTTP 连通性
ping -c 4 host              # ICMP 连通性
dig example.com             # DNS 查询（需安装 dnsutils）
```

排查网络时按“本机地址 -> 路由 -> DNS -> 端口监听 -> 防火墙 -> 应用协议”逐层验证。

## 6. 服务与日志

```bash
systemctl status nginx
sudo systemctl restart nginx
sudo systemctl enable nginx
journalctl -u nginx -n 100 --no-pager
journalctl -u nginx -f
```

`systemctl` 管理 systemd 服务状态；`journalctl` 用于查询 systemd 日志。修改服务配置前应先执行对应的语法检查命令。

## 7. 软件与系统信息

```bash
sudo apt update
apt list --upgradable
apt-cache policy package
uname -a
lsb_release -a
lsblk -f
```

## 8. 安全操作清单

1. 执行破坏性命令前先用只读命令确认目标路径、用户和环境。
2. 不将密钥、令牌或密码写入 shell 历史、命令行参数和日志。
3. 生产环境变更应记录命令、时间、影响范围和回滚步骤。

## 面试辅导

### 面试考点全景图

| 维度 | 回答要点 | 面试高频追问 |
| --- | --- | --- |
| 核心定义 | Ubuntu 命令用于观察和管理文件、进程、网络、服务与软件包。 | 命令执行成功是否表示系统状态正确？ |
| 关键角色 | shell、进程、文件描述符、权限、systemd、APT。 | 命令的权限要求和作用范围是什么？ |

### 面试官追问链

1. 如何定位某个端口被哪个进程占用？
2. 服务启动失败时，如何结合 `systemctl` 和 `journalctl` 排查？
3. 为什么 `kill -9` 不能作为常规停止方式？
4. 如何确认磁盘空间异常是文件占用还是已删除文件仍被进程持有？
5. 如何把排障命令自动化，同时控制权限和误操作风险？

### 横向对比

| 对比项 | `ps` | `top` | `systemctl` |
| --- | --- | --- | --- |
| 关注对象 | 进程快照 | 动态资源 | systemd 服务单元 |
| 适用场景 | 精确筛选、脚本 | 实时观察 | 启停与状态管理 |
| 局限 | 非实时 | 不适合批处理 | 不展示所有进程细节 |

### 缺失知识点与工程注意事项

- `rm`、重定向和 `sudo` 组合使用前必须确认展开后的实际目标；不要在不确定变量内容时执行删除。
- `grep` 未找到内容会返回非零状态，这在脚本中不一定是错误，应按业务语义处理。
- 端口监听、网络可达和应用健康是不同层次的检查，不能互相替代。

### 可能的面试题

- **问题：** “线上服务无法访问时，你如何从 Ubuntu 命令层面进行分层排查？”
- **简要答案：** 先确认服务进程和监听端口，再检查本机路由、DNS、防火墙和日志；每一步用命令验证状态，不凭单一现象推断原因。
