Ubuntu 是桌面开发、云服务器和 C/C++ 学习中常用的 Linux 发行版。本节以虚拟机安装为例说明基础步骤。

## 一、安装前的准备

1. 准备虚拟机软件、Ubuntu LTS 安装镜像和至少 2 CPU、4 GB 内存、25 GB 磁盘空间。
2. 在 BIOS/UEFI 中启用 CPU 虚拟化扩展（Intel VT-x 或 AMD-V）。
3. 从 [Ubuntu 官方下载页](https://ubuntu.com/download) 获取镜像，并校验 SHA256 值。

## 二、安装与首次配置

```text
创建虚拟机 -> 挂载 Ubuntu ISO -> 安装系统 -> 创建普通用户
    -> 安装 OpenSSH / build-essential -> 更新软件包索引 -> 快照备份
```

安装完成后执行：

```bash
sudo apt update
sudo apt install -y build-essential gdb git vim openssh-server
```

使用 `lsb_release -a`、`gcc --version`、`gdb --version` 和 `systemctl status ssh` 验证系统与开发工具链状态。

### 面试官追问链

1. **基础：** 请定义 `安装Ubuntu`，说明它的输入、输出和核心约束。
2. **机制：** 命令语义、文件/进程/权限模型、配置生效范围和错误诊断；关键状态如何变化？
3. **深入：** 与相近命令、配置方式或系统服务相比，生效时机、作用范围、权限要求、可移植性和回滚成本有什么不同？
4. **工程：** 失败、边界输入、资源耗尽或并发访问时如何保持正确性？
5. **优化：** 用哪些时间、空间、吞吐或可观测性指标验证优化有效？

### 缺失知识点与工程注意事项

- 生产操作前应确认权限、目标环境、配置备份和可回滚方案；不要只验证命令成功退出。
- 回答时应区分标准/系统保证与具体实现细节；未定义行为和未检查错误码不能作为可靠前提。
- 测试至少覆盖正常路径、边界路径和失败路径，并验证资源是否按预期释放或回收。
