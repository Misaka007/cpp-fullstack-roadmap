# C++14 新特性

## 核心特性

| 特性 | 作用 | 典型场景 |
| --- | --- | --- |
| 泛型 Lambda | 参数使用 `auto` 推导 | 通用回调、算法谓词 |
| 返回类型推导 | 普通函数可省略尾置返回类型 | 简化包装函数 |
| 初始化捕获 | 捕获时创建或移动对象 | 异步任务转移所有权 |
| `std::make_unique` | 安全构造唯一所有权对象 | 替代裸 `new` |
| `std::integer_sequence` | 编译期整数序列 | 元组展开、参数包索引 |
| 二进制字面量/数字分隔符 | 提高常量可读性 | 位掩码、容量常量 |

## 泛型 Lambda 与初始化捕获

```cpp
auto add = [](auto lhs, auto rhs) { return lhs + rhs; };

auto task = [socket = std::move(fd)]() mutable {
    // socket 的所有权已转移进闭包对象。
};
```

- 泛型 Lambda 的 `auto` 参数本质上对应闭包类的模板 `operator()`。
- 初始化捕获适合把 `unique_ptr`、socket 包装器等移动进异步任务；闭包是否可复制取决于捕获对象。
- `mutable` 允许修改闭包内按值捕获的副本，不会修改外层同名对象。

## `make_unique` 与异常安全

```cpp
auto user = std::make_unique<User>(name, id);
```

- `make_unique` 将分配与对象构造封装在一个表达式中，避免多参数调用中裸 `new` 与异常交错导致泄漏。
- C++14 不提供数组大小推导的 `make_unique<T[]>(n)` 之外的数组形式；多维数组仍需更明确的封装。

## 特性补充清单

| 特性 | 说明 | 工程注意事项 |
| --- | --- | --- |
| `decltype(auto)` | 按 `decltype(expr)` 规则推导返回类型 | 返回局部对象括号表达式可能意外推导为引用 |
| 放宽 `constexpr` | 允许局部变量、循环和分支 | 仍需满足常量求值路径的规则 |
| 变量模板 | `template<class T> constexpr T pi = ...;` | 适合类型相关常量，注意 ODR 与头文件定义 |
| 聚合初始化扩展 | 支持更多聚合类成员初始化 | 版本差异需用目标编译器验证 |
| 二进制字面量 | `0b1010'0101` | 位掩码要同时说明位宽和符号性 |
| 数字分隔符 | `1'000'000` | 仅提升可读性，不改变数值或类型 |
| `[[deprecated]]` | 标记废弃 API | 在替代 API、迁移期限和诊断中给出明确路径 |
| `shared_timed_mutex` | 读多写少场景的共享锁 | 防止写者饥饿，锁粒度需经压测确定 |
| 异构查找 | 使用透明比较器避免构造临时键 | 常见形式为 `std::less<>` 与 `find(string_view)` |
| 元函数别名 | 如 `_t`、`_v` 风格简化 traits | 区分类型别名和布尔/数值变量模板 |
| `std::get<T>` | 按类型访问 tuple | 类型必须唯一，否则应按索引访问 |

## 逐项详解

| 特性 | 机制与价值 | 典型写法 | 使用边界 |
| --- | --- | --- | --- |
| 泛型 Lambda | Lambda 参数中的 `auto` 变为闭包类的成员函数模板参数。 | `[](auto&& x) { return normalize(x); }` | 泛型回调的约束不直观；复杂接口在 C++20 可用 concepts 表达要求。 |
| 初始化捕获 | 在闭包内部声明并初始化一个捕获成员，可移动资源。 | `[p = std::move(ptr)] { use(*p); }` | 闭包可能因此不可复制；任务调度器若要求可复制回调，需要调整接口。 |
| 函数返回类型推导 | 普通函数可由所有 `return` 表达式推导返回类型。 | `auto sum(int a, int b) { return a + b; }` | 不同返回分支须推导为同一类型；递归函数通常仍需显式返回类型。 |
| `decltype(auto)` | 按 `decltype` 规则推导，保留引用和 `const`。 | `decltype(auto) get() { return (member_); }` | 加括号可能返回成员引用；返回局部变量引用会悬空。 |
| 放宽 `constexpr` | 常量求值函数中允许局部变量、循环和分支。 | `constexpr int sum_to(int n) { int r=0; for (...) r+=i; return r; }` | 能写在 `constexpr` 函数中不代表每次调用都在编译期执行。 |
| 变量模板 | 把类型相关常量声明为模板变量。 | `template<class T> constexpr T pi = T(3.1415926);` | C++14 的变量模板定义在头文件时需关注链接与 ODR；C++17 inline 变量更直接。 |
| 聚合初始化扩展 | 扩大可用花括号初始化的类形式。 | `Aggregate value{1, "ok"};` | 聚合定义随标准演进；库接口不要依赖不同编译器的边缘判断。 |
| 二进制字面量 | 用 `0b` / `0B` 直观表达位值。 | `constexpr auto mask = 0b0011'1100;` | 指明底层位宽、符号性和协议端序，避免仅看二进制文本猜含义。 |
| 数字分隔符 | 单引号按位分隔数字，提高可读性。 | `1'000'000`, `0xFF'00` | 不影响数值、类型或溢出规则。 |
| `[[deprecated]]` | 令编译器在使用旧 API 时产生诊断。 | `[[deprecated("use parse_v2")]] void parse();` | 废弃信息必须给迁移方法和版本计划，不能只制造告警噪音。 |
| `shared_timed_mutex` | 允许多个读者共享锁，写者独占锁并支持定时操作。 | `std::shared_lock lock(mutex);` | 读多并不必然更快；竞争、写者饥饿和锁升级都要压测与设计。 |
| 异构查找 | 透明比较器允许用不同但可比较的 key 查询关联容器。 | `std::map<std::string, V, std::less<>> m; m.find("id");` | 比较器必须声明透明性并满足严格弱序；避免为查找构造临时 `string`。 |
| 元函数别名 | `_t` 将 `typename Trait<T>::type` 简化为别名。 | `std::remove_cv_t<T>` | `_v` 是变量模板，不是类型；在旧标准模式需使用原始写法。 |
| 按类型访问 tuple | `std::get<T>` 用唯一类型取值，减少硬编码索引。 | `std::get<std::string>(item)` | 若 tuple 中同类型出现多次会无法编译，此时用索引或具名结构体。 |

### 横向对比

| 对比项 | 按值捕获 | 引用捕获 | 初始化捕获 |
| --- | --- | --- | --- |
| 生命周期 | 闭包持有副本 | 依赖外层对象 | 闭包持有新初始化对象 |
| 可移动资源 | 不适合 `unique_ptr` | 仅借用 | 支持 `std::move` 转移 |
| 异步安全性 | 通常较高 | 易悬空 | 取决于资源语义 |

### 缺失知识点与工程注意事项

- 不要在长生命周期回调中隐式捕获 `[&]`；明确列出捕获对象及其所有权。
- 返回类型推导会成为接口的一部分；公开库 API 需要稳定类型时可显式声明返回类型。
- `make_unique` 默认表达唯一所有权，若需要共享生命周期应明确使用 `make_shared` 并评估控制块开销。

### 代码注释提示

```cpp
// 生命周期：初始化捕获将资源移动到闭包，任务执行完由闭包析构释放。
// 泛型：auto 参数会生成模板 operator()，需确认支持的最小操作集合。
```

### 可能的面试题

- **问题：** “初始化捕获为什么适合异步任务？”
- **简要答案：** 它在创建闭包时直接初始化成员，可通过 `std::move` 转移唯一资源所有权，避免任务执行时依赖外层局部变量的生命周期。
